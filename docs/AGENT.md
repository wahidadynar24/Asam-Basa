# AGENTS.md — Aturan Kerja Web Pembelajaran Asam-Basa

## 01 Teknologi
React + Vite, komponen fungsional, dan CSS untuk tampilan responsif.

## 02 Penyimpanan
Gunakan localStorage untuk menyimpan progress dan skor latihan siswa secara lokal.

## 03 Struktur
Komponen utama diletakkan di `src/components/`, halaman di `src/pages/`, dan data soal di `src/data/`.

## 04 Bahasa
Gunakan Bahasa Indonesia yang baku, komunikatif, dan mudah dipahami siswa SMA.

## 05 Pembelajaran
Gunakan model 5E secara berurutan: Engage → Explore → Explain → Elaborate → Evaluate.

## 06 Interaksi
Utamakan aktivitas interaktif seperti simulasi pH, slider konsentrasi, klasifikasi larutan, dan kuis dengan feedback langsung.

## 07 Tampilan
Gunakan desain modern, clean, sederhana, responsif, dan menarik untuk siswa SMA. Hindari halaman yang terlalu penuh dengan teks.

## 08 Notasi Kimia
Tulis notasi kimia dengan benar, seperti H⁺, OH⁻, H₂O, HCl, CH₃COOH, NaOH, pH, dan pOH.

## 09 Akurasi
Pastikan konsep dan perhitungan kimia benar, terutama hubungan pH, pOH, [H⁺], dan [OH⁻].

## 10 Validasi
Pastikan setiap tombol, navigasi, simulasi, kuis, perhitungan, dan penyimpanan progress dapat digunakan tanpa error.
